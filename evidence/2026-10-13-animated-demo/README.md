# 原生动画与自定义速度：历史实测证据

这是 **2026-10-13** 动画候选的真实记录，在 10 月 16 日整理到公开仓库。
当日源文件、原生画面及运行 App 身份见 `source-manifest.json`。
整理和复制文件不会产生新的运行验收结论；本轮没有重新下装或发起轴运动。

![真实 NC 仿真画面录制片段](nc-motion-recording.gif)

动图来自一轮 60 mm/s 自动定位的 **20 张实际画面捕获**，按原观测间隔回放，单次录制片段循环播放。
没有生成中间运动帧，没有用手写位置积分或合成运动代替 NC 反馈。
这是历史录制的采样间隔，不用于推断当前面板的实际帧率。

## 实际通过的范围

- `acceptance.json`：16 项原生按钮/输入交互检查，包括自定义目标45 mm、速度15 mm/s、定位、自动序列、停止保持/释放、越界拒绝和复位。
- `animation.json`：20 / 60 mm/s 两组自动三次定位，峰值速度分别约20 / 60 mm/s，实测整轮耗时9.713 / 4.639秒。
- 在30 / 80 / 0 mm稳定位置，捕获的蓝色滑台位置与真实NC位置一致。运动中的界面刷新可以落后于采样值，不要求每个异步观测点像素和轴位置同时一致。
- 10份公开ST与实际编译工程的声明/实现逐份比对；公开TcVIS与当日已测原生TcVIS字节一致。
- `monitor.csv`、`monitor-animation.csv` 保留真实时间戳和采样值；它们是ADS观测，不是PLC同周期原子快照。
