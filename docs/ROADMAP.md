# 长期路线

优先完成真实 NC/PTP 单轴、PLCopen 状态机、测试记录和中文复演说明。
阶段完成以 GitHub 里程碑及实际证据为准，不能只因代码提交而关闭运行验收任务。

## 后续方向

- 更完整的故障恢复、手动点动、速度/加减速参数与边界测试。

每个方向使用独立 Issue 与验收范围。源码质量、现场解释和真实证据优先于界面美化。
