# 10 月 22—24 日 PLC / 伺服求职展示

目标：用一份能复演的运动控制作品，说明自己能理解并解释 PLC 流程、NC 轴、驱动接口、运动反馈和异常恢复。
当前无真实电机、驱动器或 EtherCAT 硬件，所有场景均明确标为 NC 软件仿真。

## 当前基线

- 已有真实 NC/PTP 仿真轴、PLCopen 功能块、内置动画面板、手动目标/速度、三次自动定位、停止保持/释放、越界拒绝/复位。
- 10 月 13 日动画候选已有 16 项界面检查及 20/60 mm/s 运动、动画位置检查记录；这些历史结论只覆盖对应源文件和 App。
- 双击启动入口已有复用运行中实例的实测记录；完整冷启动流程、当前候选核心回归和单一操作者复演仍需补齐。
- 用户反馈画面目前已恢复流畅。暂不迁移 HMI，不修改未查明原因的刷新配置。

## 90 秒展示给 HR

1. 介绍：这是我维护的 PLC/伺服运动控制作品，使用 TwinCAT 官方 NC 仿真轴，目前没有连接真实电机。
2. 点击自动演示，指着动画说明三处定位与实际位置反馈。
3. 发起一次定位，在运动中停止，再释放停止保持；说明操作不是等待固定时间后假定完成。
4. 发送 101 mm，说明行程是 0—100 mm，越界命令会被程序拒绝；复位后不自动重启。
5. 展示代码仓库及对应验证记录。只演示当前实际通过的功能，不预告尚未完成的亮点。

## 3 分钟展示给技术面试官

- 说明 `GVL_Hmi → FB_HmiAdapter → FB_ServoAxis → AXIS_REF/NC` 的命令与反馈链路。
- 用 MC_MoveAbsolute 的 Execute 上升沿、Busy、Done、Error 解释一次定位如何完成。
- 说明 MC_Stop 为什么停止后需要释放，以及它与安全急停的区别。
- 区分虚拟 MC_Direct 建立零点和真实机械寻原点。
- 若已加入曲线，解释速度变化与实际位置变化；若尚未加入，不用示意曲线冒充实测结果。
- 说明接真机还需完成总线/驱动配置、比例/方向、原点/限位、负载整定和独立安全验证。

## 冻结版现场验收

- 从电脑重启后的状态，仅通过记录的入口完成启动并打开唯一正确面板。
- 自动三次定位、手动自定义速度、运动中停止/释放、越界拒绝/复位实际通过。
- 测试时只有一个操作者发命令。读曲线、采样与录屏可以并行，控制指令不能互相抢占。
- 退出软件后仍能找到工程与启动入口；有真实录制的离线备份和中文说明。
- 文件/构建/App 与验收记录绑定，不把历史 PASS 迁移给之后修改的候选。
- 现场版本冻结后，拓展功能只在独立候选里开发。
