# Servo Motion Lab：PLC / 伺服运动控制作品

仓库：https://github.com/biaobiao2233/servo-motion-lab

**当前作品：TwinCAT 3 NC/PTP 单轴定位仿真。**
没有接真实电机；运动由官方NC仿真轴执行，界面显示PLC/NC反馈。
代码、实际记录和验证边界公开，可用于讨论实现方法。

## 可以现场展示什么

| 操作 | 可以解释的工程问题 |
|---|---|
| 使能、虚拟回零、自动30→80→0mm | 状态机与PLCopen功能块反馈，如何判断到位 |
| 修改目标和速度再定位 | 操作参数与运动命令分离，开始时锁存有效参数 |
| 运动中停止、释放后再次定位 | MC_Stop的减速过程与停止保持，取消后如何恢复 |
| 发送101mm、错误复位 | 0—100mm软件范围检查、错误编号与禁止自动重启 |
| 对照动画、NC位置和实际记录 | 数据从哪里来，异步界面刷新与控制周期有什么区别 |

## 控制结构

`原生面板 → GVL_Hmi → FB_HmiAdapter → FB_ServoAxis → AXIS_REF / NC仿真轴`

`NC / 功能块反馈 → GVL_Monitor → 原生面板与采样记录`

使用ST、Tc2_MC2、MC_Power、MC_Home、MC_MoveAbsolute、MC_Stop和MC_Reset。
使用官方Automation Interface创建/构建工程，用ADS读取状态、执行受限的仿真命令。
AI用于辅助代码、工具和调试；展示时需由本人独立操作并解释关键逻辑。

## 面试前必须能独立回答

1. Execute为什么需要上升沿？Busy、Done、Error分别表示什么？
2. 为什么不能用“等三秒”判断运动完成？超时定时器用来做什么？
3. 输入框里的目标、已接受目标、NC实际位置为什么可能不同？
4. 虚拟回零与真实原点开关回零有什么区别？
5. 为什么MC_Stop完成后仍可能锁轴？为什么它不等于安全急停？
6. 如果接实际伺服，还缺哪些工作？

最后一题的范围：具体PLC/总线/驱动型号、接线、编码器和机械比例、方向、原点/限位、
负载和整定、通信故障、独立安全系统及对应硬件验收。当前仿真不替代这些工作。
